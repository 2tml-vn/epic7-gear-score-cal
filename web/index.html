Score formulas

Lv 85 · Epic & Heroic ATK% + HP% + DEF% + EFF% + ER% + SPD×2 + CC%×1.6 + CD%×(8/7)
Lv 88 · Epic (ATK% + HP% + DEF% + EFF% + ER%)×10/9 + SPD×2 + CC%×10/6 + CD%×10/8

Level 85 uses the 8-point system; Level 88 uses the 10-point system. Rarity changes the target, not the formula.

How the numbers are built

  • Rolls = base rolls + enhancement ÷ 3. Epic starts with 4 rolls, Heroic with 3.
  • Benchmark = rolls × target per roll (6.08 / 7.04 / 8.04).
  • Max roll value = 8 points on Lv 85, 10 points on Lv 88 — every non-flat stat.
  • Reachability = current score + remaining rolls × max roll value ≥ benchmark.
  • The Lv 85 average: (5×6.00 + 6.00 + 6.29 + 6.40) ÷ 8 = 6.0857 ≈ 6.08.
  • The Lv 88 target of 8.04 is the calibrated 10-point-system average per roll.
  • Main stats, set bonuses, and flat stats are not part of the score.
